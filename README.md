# AI PR Reviewer
**The repository is not completed yet and is under development**

Repository-aware AI code review agent.

## Stack

- Backend: Python + FastAPI
- Frontend: React + TypeScript
- Database: PostgreSQL + pgvector
- Queue: Redis + Celery
- AI: LLM provider + LangChain/LangGraph when justified
- GitHub: GitHub App + Webhooks + REST/GraphQL
- Testing: pytest
- Deployment: Docker + GitHub Actions
